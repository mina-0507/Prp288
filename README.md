## Задание: Напишите две функции для решения задач своего варианта - с использованием рекурсии и без.
#### Условие задания: Функция, которая разделяет список на n частей.

### БЕЗ РЕКУРСИИ:
1. Создание функции split1, которая принимает список lst и число n (количество частей).
2. Внутри функции создан пустой список result для хранения количества частей.
3. С помощью цикла for i in range(n) в result добавлено n пустых списков (под каждую часть).
4. Запуск цикла по индексам исходного списка (от 0 до len(lst)-1).
5. Для каждого элемента с индексом i определён номер части с помощью операции остатка от деления: i % n.
6. Элемент добавлен в соответствующий подсписок через result[i % n].append(lst[i]).
7. Готовая структура из n списков с распределёнными элементами возвращена из функции.

### С РЕКУРСИЕЙ:
1.  Создание рекурсивной функции split2, которая принимает список lst, количество частей n, текущий индекс i и накопитель res.
2.  При первом вызове (когда res is None) создаётся список res, содержащий n пустых подсписков.
3.  Если текущий индекс i достиг или превысил длину списка lst, функция возвращает готовый список res.
4.  В рекурсивном шаге элемент с индексом i из исходного списка добавляется в подсписок res[i % n].
5.  Функция вызывает саму себя с увеличенным на единицу индексом i + 1 и обновлённым списком res.

# ЗАДАНИЕ 2
## Задание: Напишите две функции для решения задач своего варианта - с использованием рекурсии и без.
#### Условие задания: Функция для расчёта $`v_i = \frac{i+1}{i^2 + 1} v_{i-1} - v_{i-2} v_{i-3}`$. $`v_1 = v_2 = 0, v_3 = 1.5`$.

### БЕЗ РЕКУРСИИ:
1. Создание функции calc1(n) для вычисления n-го элемента последовательности.
2. В списке v сохранены начальные три значения: v[0] = 0 (v₁), v[1] = 0 (v₂), v[2] = 1.5 (v₃).
3. Добавлены условия для быстрого возврата значений при n = 1, n = 2 или n = 3 без вычислений.
4. Запущен цикл for i in range(4, n + 1) для вычисления элементов с 4-го по n-й.
5. Внутри цикла новое значение v_i рассчитано по формуле:  
   $`\frac{i+1}{i^2 + 1} v_{i-1} - v_{i-2} v_{i-3}`$.
6. При вычислении выполнена индексация списка:  
   v[i-2] соответствует $`v_{i-1}`$,  
   v[i-3] — $`v_{i-2}`$,  
   v[i-4] — $`v_{i-3}`$.
7. Каждое новое значение добавлено в список v методом append().
8. Функция возвращает v[n-1] (поскольку в списке индекс 0 хранит v₁).

### С РЕКУРСИЕЙ:
1.  Создание рекурсивной функции calc2(n) для вычисления n-го элемента последовательности.
2.  Если n равно 1 или 2, функция возвращает 0; если n равно 3 — возвращает 1.5.
3.  Для всех остальных случаев (n > 3) функция реализует рекурсивный вызов.
4.  Выполнены три рекурсивных вызова для получения значений трёх предыдущих элементов:  
    v1 = calc2(n-1) (значение $`v_{i-1}`$),  
    v2 = calc2(n-2) (значение $`v_{i-2}`$),  
    v3 = calc2(n-3) (значение $`v_{i-3}`$).
5.  Итоговое значение v_n рассчитано по формуле:  
    $`\frac{i+1}{i^2 + 1} v_{i-1} - v_{i-2} v_{i-3}`$.
6.  Рассчитанное значение возвращено как результат функции.
